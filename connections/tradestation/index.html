Connections/Futures brokers

How to connect

TradeStation.

TradeStation exposes brokerage and market-data services over HTTPS, with a separate simulation service. Its developer onboarding uses an API key and OAuth.

Alpharch supportIntegration & provider access required

Alpharch still needs an implemented, tested adapter and any required provider approval. Having an account alone does not enable this connection.

Before you start

  • An account with the required products and data permissions.
  • Approved application access and an implemented Alpharch OAuth adapter.

Prepare your connection

  1. Confirm developer access

    Review TradeStation’s API onboarding and permissions for the intended account.

  2. Separate data from account access

    Identify the futures instruments and streaming data needed for your charts.

  3. Authorize only when supported

    The planned connection is browser authorization. Alpharch does not currently provide a working TradeStation login.

If something is missing

Expecting the desktop app to be required

The documented API is HTTPS-based. Linux feasibility comes from that API, not from a claim that TradeStation’s desktop software runs natively on Omarchy.
