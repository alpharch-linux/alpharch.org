Connections/Crypto exchanges

How to connect

Deribit.

Deribit separates public data methods from authenticated private account methods. Alpharch’s existing alphaopt tool uses public options data; it is separate from the new chart desk.

Alpharch supportAvailable in existing tools

Public data is available in the existing Alpharch tools. Account linking and broker execution are separate features.

Before you start

  • A supported Alpharch adapter for this exchange and product.
  • Regional availability and the provider’s current data-use conditions.

Connect the existing tool

  1. Open the options tool

    Launch alphaopt from the installed Alpharch tools. Read its help for supported assets and views.

  2. Choose the options view

    The existing tool includes a tape and open-interest map. Open interest is not the same thing as traded flow or dealer positioning.

  3. Keep the account separate

    Reading this public options feed does not connect an account or enable execution. The new desk does not yet contain a full Deribit chart adapter.

If something is missing

Price differs from another venue

Check the exchange, product, quote currency and contract. Do not substitute another exchange’s price.

Connection unavailable in your region

Use a provider available to you. Do not bypass regional access restrictions.
