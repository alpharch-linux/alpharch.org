How to connect

CQG.

CQG can connect a Linux application through its Web API. Production access requires application identifiers and conformance; browser authorization also requires CQG app registration.

Alpharch supportIntegration & provider access required

Alpharch still needs an implemented, tested adapter and any required provider approval. Having an account alone does not enable this connection.

Before you start

  • A CQG account enabled by the broker for the intended application and exchanges.
  • Alpharch registration, adapter implementation and production conformance.

Prepare your connection

  1. Identify the CQG account

    Use the CQG credentials supplied for your trading platform, not an unrelated broker-portal login.

  2. Check account access

    Confirm the exchange subscriptions and third-party platform permissions with your broker.

  3. Use the supported authorization route when released

    CQG documents user logon and registered OAuth with PKCE. Alpharch has not released either route; this website does not collect credentials.

If something is missing

Application or private-label error

The software’s CQG registration must match the account’s permissions. This is not fixed by repeatedly changing your password.

Quotes without depth

Ask for the data entitlement needed for the exact contract and view. Top-of-book access does not supply a full ladder.
