How to connect

NinjaTrader.

A NinjaTrader login does not automatically authorize another charting application. NinjaTrader’s account FAQ documents Continuum / CQG credentials for applicable accounts; confirm your account’s actual route.

Alpharch supportAccount route needs verification

The correct API route or account permissions have not been fully verified. There is no working Alpharch connection to claim here.

Before you start

  • Written confirmation of the connection available to your specific account.
  • A tested Alpharch adapter for that route.

Prepare your connection

  1. Find the account’s connection details

    Check your account documentation or ask NinjaTrader which third-party data route is enabled.

  2. Match the route

    If you were issued CQG credentials, read the CQG guide. Only use Tradovate API instructions if that route is explicitly enabled for your account.

  3. Check release support

    NinjaTrader is not a working broker connection in the current Alpharch release.

If something is missing

NinjaTrader website password is rejected

Brokerage, website and data-provider credentials can serve different purposes. Confirm the required login instead of trying every connection type.
