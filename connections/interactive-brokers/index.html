Connections/Futures brokers

How to connect

Interactive Brokers.

IBKR supplies Linux builds of TWS and IB Gateway. An Alpharch connection through the TWS API still needs an adapter and account testing.

Alpharch supportAdapter not released

The provider offers an integration route. Alpharch does not yet offer a working connection for it.

Before you start

  • An IBKR account and its required market-data subscriptions.
  • The Linux TWS or IB Gateway application, signed in locally.

Prepare your connection

  1. Install the official Linux application

    Download TWS or IB Gateway from IBKR. Gateway uses fewer desktop resources; TWS also lets you inspect the same data in its own interface.

  2. Prepare the local API connection

    In the application’s API settings, enable socket clients, retain read-only access for charting, and note the socket port. Keep access on this computer.

  3. Confirm your market data

    Check the exact futures contract and exchange in IBKR. Quotes, tick-by-tick subscriptions and market depth have different permissions and limits.

  4. Connect when the Alpharch adapter is available

    The planned flow selects the local gateway, port and environment. This guide does not mean an IBKR account can connect to the current Alpharch release.

If something is missing

Gateway opens but no chart data

Check that you are signed in, the API is enabled and the socket port matches. A successful socket connection alone does not establish a market-data entitlement.

A ladder or footprint is missing detail

Check depth and tick-by-tick permissions and subscription limits. Ordinary watchlist quotes do not establish full-depth or market-by-order coverage.
