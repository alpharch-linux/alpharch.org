Connections/Futures brokers

How to connect

Tradovate.

Tradovate documents a web API with OAuth and separate live, simulation and market-data services. Account eligibility and API access must be confirmed before an Alpharch integration can be used.

Alpharch supportIntegration & provider access required

Alpharch still needs an implemented, tested adapter and any required provider approval. Having an account alone does not enable this connection.

Before you start

  • An eligible account with API access and the required exchange subscriptions.
  • A registered and tested Alpharch integration. Prop-firm access must be checked separately.

Prepare your connection

  1. Confirm API eligibility

    Check the current API-access requirements in Tradovate’s official documentation and your account settings. A platform login is not proof of API access.

  2. Identify the environment

    Keep live and simulation accounts distinct. Market-data permission is separate from the ability to sign in.

  3. Authorize when supported

    A released third-party connection should direct you through the supported authorization flow. Alpharch’s Tradovate adapter is not available yet.

If something is missing

Demo or prop account will not authorize

Ask the account provider whether third-party API use is allowed for that specific account.

Account appears but quotes do not

Check API and exchange-data permissions, then the exact contract symbol and environment.
