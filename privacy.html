ALPHARCH / PRIVACY / SEPTEMBER 7, 2026

Installation reports are your choice.

Alpharch works the same whether you share a report or not. Reporting is off by default.

What you’re asked.

After a successful installation, the terminal asks whether you want to help count completed installs. Pressing Enter, answering No, or leaving the question unanswered keeps reporting off. Unattended installations default to off. Your choice is saved, so updates don’t keep asking.

Check your choice with alpharch install-reports status. Turn it on with alpharch install-reports on or off with alpharch install-reports off. Enabling it later covers future installs and updates, not past activity.

Exactly what is sent.

  • Whether this was a fresh installation, an update to a different build, or a reinstall of the same build.
  • The Alpharch version and source build revision.
  • A random report ID that prevents a retry from being counted twice. Each installation event gets a new ID; there is no persistent device ID.

The server adds the date it received the report. There are no account names, broker credentials, trades, positions, charts, watchlists, recordings, journal entries, hardware identifiers, location fields or usage history in the report.

Where reports go.

Reports are sent over HTTPS to Alpharch’s reporting service, hosted on OpenAI Sites with Cloudflare infrastructure. Network requests expose the connection IP and standard request information to hosting providers; their infrastructure may retain operational logs. The Alpharch reporting database does not store IP addresses or request headers.

The project owner can view aggregate counts in a private dashboard. Minimal report records are retained for release statistics and retry deduplication until removed by the maintainer. Reports do not measure unique people or active traders.

No background tracking.

The report is attempted only after installation succeeds. Nothing is reported when you open charts or use Alpharch. A network failure doesn’t fail the installation. Up to ten unsent reports can be kept locally and retried during a later installation, using the same IDs.

Turning reporting off clears unsent reports and stops future reporting. It does not retract reports already received. Your local choice is in ~/.config/alpharch/install-reporting.json; local receipts and pending reports are in ~/.local/state/alpharch/install-reporting.json. Configuration is preserved on uninstall.

Installing without a prompt.

To explicitly decline while using the one-line installer:

curl -fsSL https://alpharch.org/install | bash -s -- --install-reports=off

Change off to on only if you want to opt in. You can review the reporting source.

The website and market feeds.

This installation counter does not track visits to alpharch.org. GitHub Pages and market-data providers receive requests independently when you use those services. Connecting a feed or broker is separate from consenting to installation reports.
