Set up your Hyprland desk.

Start with Omarchy, add Alpharch, then choose your charts. This guide covers the current public installer, the Hyprland desk and the futures and crypto tools available today.

What’s available?

Alpharch is being built for futures and crypto traders. ES and NQ remain central to the futures workflow. Public crypto feeds let you try the live desk without a licensed broker connection.

Available in the public preview: the current installer delivers the Hyprland desk shown here, with separate native chart windows, starting templates, searchable studies, drawings and local replay. Classic desk remains available in one window. The terminal order-flow tools, crypto options, desk launching, morning brief, calendar and journal remain included.

Run alpharch update for the latest Hyprland desk and startup fixes, even if your version already reads 1.8.0-alpha.1. The initial preview release notes describe the earlier baseline; this guide covers the current installer.

The development IBKR bridge is read-only and has passed offline checks. A real gateway and account connection still need acceptance testing. Rithmic/CQG adapters and live broker execution are not implemented. See the provider guides before arranging data access.

Install the public overlay.

  1. Start with Omarchy already installed. Alpharch adds to your desktop; it is not an operating-system image. Use the official Omarchy instructions if you need to install the base system first.
  2. Open a terminal and run the installer. You can read the source first. The installer may request permission to install missing dependencies.
curl -fsSL https://alpharch.org/install | bash

  1. Open your desk. Select Alpharch Live Desk in the app launcher, press SUPER+ALT+V, or run trade-workspace. Choose Hyprland desk, pick a starting layout, and select Open. Use alpharch version to check the version and alpharch doctor to check tools and feeds. If you already have Alpharch, run alpharch update first.

Installation reports are optional and off by default. The installer asks once after it succeeds. See exactly what is sent and how to change your choice.

Public Coinbase/Kraken spot, Hyperliquid perpetual and Deribit options tools do not require a trading-account login. Reachability depends on your location and the provider. Legacy Binance connections can be region-restricted. Futures exchange subscriptions and optional third-party services are separate from Alpharch’s free software license.

LIVE DESK PREVIEW

Choose a starting desk.

The main desk shows the chooser every time it opens. Select Hyprland desk, then a layout: each chart opens in its own window on an available workspace. Omarchy handles the tiling. The Classic desk option keeps charts together in one window. Continue current desk or Escape returns to an existing Classic layout; without a saved desk, closing the chooser starts empty.

  • Bitcoin desk: one-minute candles, captured VWAP and volume, a 15-second liquidity heatmap, and time & sales. All three charts use Coinbase BTC/USD and share a symbol-link group.
  • Crypto overview: BTC, ETH and SOL on independent five-minute Coinbase charts, each with EMA 20 and volume.
  • Single chart: one large Bitcoin chart with volume below.
  • Blank desk: no charts or subscriptions until you add them.

Use Desk → Choose a starting desk to switch later. Your Hyprland and Classic desks are saved separately. In a Hyprland window, Desk → Save Hyprland desk saves your open native charts; saved desks appear in that menu. Classic keeps a Restore previous desk recovery slot when you change its template. Save a named layout or export it to keep more versions.

ES/NQ starting presets are planned after the live-data connection workflow is verified. Heatmaps, captured VWAP and order-flow studies need time to collect trades and book updates. An empty area at the start is not filled with sample data.

LIVE DESK PREVIEW

Make room for your charts.

In the Hyprland desk, New chart or Ctrl+N lets you choose the market, feed, timeframe and view, then opens another native window. Use your normal Omarchy shortcuts to focus, resize, swap and move charts between workspaces or monitors. The desktop handles the arrangement.

Wheel over the plot to zoom time at the cursor. Wheel over the price scale to zoom price. Drag the plot to inspect earlier bars; Shift-drag moves the price range. Fit resets the view, Auto fits price, and Live returns to the latest bar.

Use ƒ for the searchable indicator library. Change periods, sources, colors and pane placement, then save a study template. The slim left toolbar holds crosshair and drawing tools. Use the timeframe shortcuts or enter a custom interval; the History control sets history per chart. Tools provides exact coordinates, alerts and footprint row grouping.

Time bars preserve elapsed-time spacing. Event bars use separate sequential positions, including when exchange timestamps match. Hover to inspect the supplied price, volume and exchange time.

The Hyprland desk has been checked with several native windows on one physical monitor. Additional-monitor and hotplug testing remains outstanding. If you choose Classic instead, drag chart titles and edges inside its single window, use Arrange to tile the page, or double-click a title to focus a chart.

Start with the morning brief.

The Daily brings together current public Coinbase spot prices for your configured watchlist, session-clock information, calendar events and yesterday’s journal debrief. Open it with trade-brief or SUPER+ALT+B.

Run trade-brief --save to append the brief to today’s journal. Your watchlist and personal calendar live in the configuration files listed below.

The current brief runs when you open it. Scheduled morning delivery, a complete overnight futures report and dealer-positioning analysis are not built into it yet. Those additions need their own implementation and suitable data; a missing number should be shown as unavailable.

Keep your setup and your record.

In a Hyprland window, use Desk → Save Hyprland desk or Ctrl+Shift+S to save your open charts, studies, drawings and workspace/monitor assignments. Reopen a named desk from that menu. Hyprland decides the tile proportions when the windows reopen; exact split ratios are not saved. Classic layouts autosave in the browser profile and have separate named-layout and export controls. Layout files contain chart settings, not account credentials.

Review → Record / replay in this desk records available live streams into local files. In Hyprland, replay is local to each window; its replay bar selects the visible stream. Classic can replay several streams on one shared clock. Play, pause, step, seek or change speed, then return to the prior live chart. Recorded depth is sampled Level 2, not every exchange book event or individual-order MBO.

The existing engine also records and replays tapes with alphad --record FILE and alphad --replay FILE --speed 4. Keep your own backup of important recordings and layouts.

Desk Brain: current and planned.

Available now: your own model account.

Desk Brain uses engine-calculated facts and your selected journal/tape context to help review a session. It is designed for reading the record, not predicting prices or placing trades.

It runs through your own Claude CLI. Invoking it sends the supplied context to that model provider; it is not offline inference. Alpharch does not supply model access, and your provider’s costs and terms apply.

trade-brain check checks setup. debrief, ask and replay work with your record. The existing do command is limited to validated desk-control parameters. Ordinary charts and the starting templates do not invoke a model.

Planned: an optional paid subscription.

A hosted Desk Brain service is planned for personalized morning briefs, explanations around watched levels, and session reviews, with included AI usage. It will use available, permitted data and show the source and timestamp behind observations. It will not place orders.

The core workspace, ordinary chart tools, local recording/replay, journals and basic Daily remain free. The paid offering is additional; current local features are not being moved behind a subscription.

Pricing, usage allowances and sharing controls will be published before subscriptions open. Hosted accounts, payments and the paid assistant service are not available yet. Market-data subscriptions and exchange permissions remain separate.

If something is missing.

The Hyprland option is unavailable.

Open Alpharch inside your running Omarchy desktop. The chooser retries while the desktop session is starting. Update Alpharch and reload the desk if you have an older build; the current installer includes automatic desktop-session detection.

A command is not found after installation.

Open a new terminal so it picks up your updated path, then try alpharch doctor.

A footprint or heatmap looks sparse.

It may have only recently started capturing data. Footprints require trade details and heatmaps require book updates. Historical candles alone cannot provide either. Check the chart’s source and status.

A broker login works elsewhere but not here.

A broker account, data subscription and third-party API permission are different things. Check the connection guide for the actual route and Alpharch’s current support. This website never collects credentials.

One window fills the workspace.

That can be normal tiling when it is the only window. Add another window on the same workspace. Saved routing and layouts depend on the monitors currently attached.

I want to update or remove Alpharch.

alpharch update updates the installed public overlay, including the new live desk. Existing custom desk rooms keep their saved commands; edit a room to use trade-workspace if it still opens an older tool. To uninstall, run ~/.local/share/alpharch/uninstall.sh. Keep an independent backup of your journal, recordings and exported layouts.

For reproducible problems, use the project’s issue tracker. Include the affected tool and error message, without passwords, API keys or account identifiers.
